# Trace2Tower: Transition-Aware EigenTrace Induction of Multi-Level Skills for LLM Agents（Trace2Tower：面向转移的 EigenTrace 多层技能归纳）

> TL;DR 把 LLM Agent 的原始成败轨迹抽象成规范事件，用"语义+转移+结果"三类证据构图，经对比谱分解剔除失败捷径，归纳出动作—程序—策略三层技能塔，实现紧凑可复用的层级经验。

## 1. 研究背景与要解决的问题

LLM Agent 越来越依赖从执行轨迹中学习经验。直觉上，历史成功轨迹里藏着金矿：有效的动作模式、有用的中间状态、恢复流程、长期策略。但**原始轨迹几乎不可直接复用**——冗长、冗余、贴着具体任务，还混着失败的试探分支。核心挑战因此是：如何把大量轨迹压成紧凑可靠的"行为结构"，既留住决策模式，又剔除任务噪声和失败捷径？

已有工作分两支，各有盲区。经验复用派（ReAct/Reflexion/ExpeL/SEER）把交互存成记忆、指南或检索片段，本质是"存什么、取什么"的搬运工——事件间的行为关系是隐式的：表面描述相似的事件可能功能不同，形态迥异的事件可能支撑同一流程。技能库派（Voyager/SkillX/Trace2Skill 等）把经验沉淀成技能工件并管理其组织，但**结构多是在既有技能之上人为施加的**，回答不了三个前置问题：哪些行为该归组、哪些行为该跟在谁后面、哪些模式导向成功而非失败。Trace2Tower 的主张很干脆：在技能尚未成型之前，直接从轨迹里归纳出"成功对齐的行为结构"，让技能层级从数据里长出来。

## 2. 核心方法 / 思路

流水线为 D→E→G→Z→T（轨迹→事件→图→谱表征→技能塔），全程参数无关、无监督：

**① 事件级抽象（E）。** 按子目标切换、动作族变化、操作对象或反馈变化，把原始 step 切成规范事件（如 WebShop 的 Query→SelectCandidate→Inspect→Configure→Purchase），再以带类型参数替换任务实体，使行为等价的事件归一到同一身份 u。节点取各出现实例的嵌入平均作表征，抹平表层语言差异，而顺序信息原样保留供转移估计。

**② EigenTrace 构图（G）。** 在有向事件图上融合三类证据：语义兼容性 s（嵌入余弦，但语义**从不创造边**，转移必须真实被观测到）、转移依赖 t±（成败转移计数归一化）、结果证据 o±（由平滑成败倾向复合）。成败各成一份亲和度 A+ 与 A−，几何平均 A±=M·ω·(s·t·o)^{1/3} 集成且无需人工配权；掩码 M 只留观测过的转移，证据强度 ω 压低单次偶发边。

**③ 对比谱分解（Z）。** 关键一步是参数无关的对比变换：Ā_uv=(A+_uv)²/(A+_uv+A−_uv)，随成功亲和度单调增、随失败亲和度单调减，系统性压制失败轨迹里的高频捷径，且有稳定性引理保证不放大亲和度估计误差。随后对每个连通分量做归一化 Laplacian 谱分解，按最大特征间隙动态定簇数，取非平凡低维 EigenTrace 表征行归一化后做 K-means；孤立节点与小于 3 节点的分量退化为单例。

**④ 技能塔归纳（T）。** 三层塔由数据自然分层：动作技能=规范事件；程序技能=谱聚类得到的稳定行为块；策略技能=把轨迹压成"去重复的程序序列"后重建对比图、缩并强连通分量，再保留有成功对比边支撑的最大路径。部署时按 token 预算做分层检索（匹配度 × 平滑可靠度），支持验证器反馈下的四种图编辑（拆分/合并/提升/降权），在**不重新归纳**的前提下修订冻结的塔。

## 3. 关键实验结果

在 ALFWorld（134 个 solvable valid_unseen 任务，用 310 训练任务的 1,240 条轨迹归纳）与 WebShop（固定 100 任务测试集，400 条轨迹）上评测；GPT-5.4 作 Skill Author、DeepSeek-V4-Flash 作默认 Skill User，交互预算统一 20 步。

- ALFWorld：Full 策略成功率 **87.31%±0.75**、平均 10.35 步、0.26 次非法动作，比最强基线 ExpeL（81.59%）高 5.72 点、比 SkillX（78.61%）高 8.70 点；轻量 High-only 也有 84.83%。而 No-Skill 仅 46.27%、专家手写 71.39%。
- WebShop：Full 精确成功率 **50.67%**，超 SkillX（49.33%）1.34 点，reward 0.7115 逼近专家手写 0.7183；非法动作从 No-Skill 的 0.68 压到 0.27。
- 上下文效率：比 SkillX 输入 token 减 30.5%、注入技能上下文减 63.9%——增益来自结构化组织而非塞更多上下文；归纳还省 16.85% 的 GPT 构造 token。
- 结构消融（ALFWorld）：去掉转移证据最致命，87.31%→70.15%，塔从 39 程序/118 策略塌缩到 19/76；去掉结果证据或对比变换都掉到 73.88%，后者塔仅剩 10 程序/44 策略——三类证据缺一不可。
- 跨模型迁移：同一座塔从 GPT-5.4 迁到 DeepSeek-V4-Flash 用户，成功率 65.67%→88.06%（配对 McNemar p=6.04×10⁻⁷），证明塔结构不绑定作者模型。
- 反馈精修：冻结塔 80.42%→TF-IDF Pareto 选择 84.58%、embedding 选择 83.75%，全程无需重新归纳。
- 规模与组织：13,724 个事件段压成 3,764 个商节点，归纳出 39 个程序（各平均聚合约 352 个事件段）与 118 条策略路径（每条由 2~4 个程序组成）；4 个程序出现在 20+ 条策略里，另 11 个无处复用——层级分工清晰。

## 4. 亮点与贡献（Why it matters）

一，补上技能学习中缺失的"结构归纳"一环：归组/转移/结果三个问题在技能工件存在之前就被显式回答，全流程参数无关、无人工配权。二，对比谱分解是干净的新机制：把成功—失败证据织进亲和度再谱聚类，稳定性有引理与 Davis–Kahan 定理双重背书，可独立复用。三，三层塔 = 可执行动作 + 可复用程序 + 可迁移策略，契合 Agent 分层规划的认知结构，而非扁平摘要。四，验证器驱动的图编辑让技能库摆脱"建完即死"，失败后可小成本修订。五，实验纪律好：同轨迹池、同预算下对比，并做了作者/用户解耦的跨模型验证，排除了"好结果来自作者模型"的混淆。

## 5. 局限与可改进点（个人点评）

其一，评测只在**文本观测**的 ALFWorld/WebShop 上做，动作空间小、状态结构化；真实 GUI（像素截图、视觉+DOM 混合、超长 horizon）里"事件抽象"难度陡增，嵌入归一对视觉同义动作是否成立完全没有证据。其二，图归纳是**离线批量**的：全部轨迹一次性喂入建塔，虽可小修小补，但"技能随经验从零长出"的终身学习愿景打折——文中没有流式增量归纳的复杂度与稳定性分析。其三，最大特征间隙定簇数、零范数节点单例化等启发式在数据稀薄时易分裂出碎片程序，对超低频成功轨迹，伪计数平滑未必兜得住。其四，归纳质量对作者模型敏感：GPT-5.4 建的塔给 Flash 用户带来 65.67%→88.06%，Flash 自建塔只有 65.67%——弱作者模型建的塔增益有限，这个底座依赖被轻轻带过。

## 6. 对 GUI Agent 的可借鉴点

GUI Agent 的轨迹日志几乎是 Trace2Tower 的理想原料：一次操作产出一条含观测（截图/DOM）、动作、状态转移与成败的结构化轨迹，且**失败轨迹往往占绝大多数**——正是"对比式失败抑制"最能发力的场景。迁移路径：① 把 GUI 步骤映射成规范事件层（OpenApp/Click/Type/Scroll/Assert/Recovery），用元素角色与类型做参数化归一，抹平"同一操作在不同截图里的表面差异"，这正是 GUI 动作泛化的老难题；② 构图时加入"前置状态→动作→后置状态"的转移证据与任务成败，自动剔除"看似正常却通向死胡同"的失败动作链，比手写 SOP 或文本相似度检索可靠；③ 谱聚类产出的程序块（"填写登录表单""定位筛选条件"）可注入 GUI 策略的上下文/技能库，token 预算约束的分层检索正好契合 GUI 智能体上下文稀缺的现实；④ "冻塔可改"机制比每次失败后重训整套策略便宜得多。落地注意：GUI 事件的语义嵌入必须融合视觉模态，纯文本嵌入会把两张截图上的同义控件切成两个节点；动作长尾极重的日志还需先做去噪再做谱聚类。

## 7. 延伸阅读

- Trace2Skill（Ni et al., 2026）：把成败轨迹蒸馏成可迁移技能目录，Trace2Tower 的直接前置与基线。
- SkillX（Wang et al., 2026a）/ Voyager（Wang et al., 2023）：技能库与终身技能学习，一个管组织、一个管涌现。
- SkillDAG（Bai et al., 2026）/ Graph-of-Skills（Liu et al., 2026）/ GraSP（Xia et al., 2026）：技能级依赖图建模，与 Trace2Tower 互补（它在技能前建结构，它们为已有技能排结构）。
- ExpeL（Zhao et al., 2024）：经验迁移 + 检索演示的经典对照，本文在 ALFWorld 上的最强基线。
- Reflexion（Shinn et al., 2023）：把环境反馈转成语言反思的并行路线。
- HiAgent（Hu et al., 2025）：长时程任务的分层工作记忆，聚焦长任务的结构化管理。
