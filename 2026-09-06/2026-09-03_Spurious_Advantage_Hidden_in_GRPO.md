## 1. 研究背景与要解决的问题

带可验证奖励的强化学习（RLVR）已是推理大模型后训练的标准配方，GRPO 是其中的主力：每个 prompt 采样一组 rollout、由二值 verifier 打分，再用组内"均值—方差"标准化把 reward 折算成 per-rollout advantage，供 PPO 式 surrogate 加权更新——这套公式对所有任务一视同仁，开放答案数学、多选题、多轮搜索轨迹共用一式。

本文指出一个被忽略的盲区：GRPO 的 per-rollout 权重实际上**只由组内对错计数 (n+, n−) 决定**。二值奖励下可化简为 Â+ = √(n−/n+)、Â− = −√(n+/n−)，与 rollout 内容、策略置信度无关，隐含假设是"拿到 +1 即推理正确"。但当 rollout 是**蒙对的**——4 选 1 撞到正确项、题库里蒙到高频答案串、搜索路径繁多总能绕回正确答案——它照样领到与真推理相同的梯度权重；且放大在失衡组里最强：G=16 时一组仅 1 条答对（n+=1），权重高达 √15 ≈ 3.87 倍，均衡组仅 1 倍。作者把这份"来自猜测而非推理"的梯度成分称为**伪优势（spurious advantage）**。

伪优势在三种结构下会变得可观：① 有界答案任务（多选题/封闭词汇 QA，答案面有限）；② 名义开放、实则大量子题答案面有限的训练集（MATH-7.5K 中按答案形态归类有 55.95% 的题属有界型）；③ 只按最终答案给奖、预算内存在大量通往同一答案路径的 search agent。训练早期策略最弱、最容易"答对"的恰是这些答案面小的简单题，策略因此被静默推向模仿"幸运猜测"而非有效推理。

## 2. 核心方法 / 思路

作者采纳 Mroueh 的闭式分解作为分析起点（GRPO 等价于自适应加权对比损失，稀有成功拿到巨大正权），但指出"稀有成功 = 稀有推理轨迹"这一前提在有界答案下并不成立。据此提出估计器 **SIGNBALANCE**，目标是让 per-rollout 的权重量级与组内构成 (n+, n−) 彻底解耦。构造分三步，每步消除一处依赖：

- **第 1 步：分 class 归一化。** 正、负 rollout 分开算统计量再标准化，答对的 rollout 不再被一大群答错的拉低/放大——但每类内部尺度仍依赖计数，不够干净。
- **第 2 步：纯符号量级。** Âᵢ = sign(rᵢ)·c，权重退化为全局常数 c，与 (n+, n−) 完全无关——但正侧总力 n+·c 与负侧 n−·c 不再相等，GRPO 依赖的"组内零均值"被破坏。
- **第 3 步：符号 + 类别力平衡（最终版）。** Â₊ = c，Â₋ = −c·sg[n+/n−]。用 stop-gradient 的类别缩放把正负两侧总力配平（∑₊|Â| = ∑₋|Â|），又不把计数依赖塞回单条 rollout 的权重里。

结果是一个可直接替换原 advantage 的估计器：无参数（除全局尺度 c）、不动 PPO surrogate、零外部模型与推理开销。类比：GRPO 像按"组里几人做对"给每题算权重，伪优势相当于"全班都不会、独一个蒙对的人领特等奖"；SIGNBALANCE 只问对错、用统一权重配平两侧总力，组内冷热不均便不再放大猜测噪声。

## 3. 关键实验结果

实验设定：主模型 Qwen2.5-0.5B-Instruct，在 MATH（约 7,500 题）上用 G=16、lr 1e-6、KL β=1e-3 训练，在 8 个数学基准上按答案面分组评测；另在 3B 验证规模扩展，在 7B 上复现 Search-R1 搜索智能体设定（每轨迹至多 B=4 次检索、outcome-only 精确匹配奖励）。基线包括 PPO、REINFORCE++、RLOO、GRPO 及 Dr.GRPO/DAPO/BNPO，所有方法共享骨干与数据，唯一控制变量是 advantage 构造。

- **0.5B 数学（Table 2）**：SIGNBALANCE 的 Avg-8 = 36.61，超过全部基线（GRPO 34.24、DAPO 36.27、BNPO 35.68）。增益集中在有界答案题：SAT-Math 71.88 vs GRPO 65.62（**+6.26**）、AQuA 35.43 vs 29.53（**+5.90**）、AMC 10.84 vs 6.02（**+4.82**）；开放答案端大体打平，MATH-500 略回撤（53.60 vs 56.60）。
- **3B 规模扩展（Table 3）**：Avg-8 = 43.78，为各组最高，比 GRPO 42.80 高 **+0.98**；单基准最大收益出现在竞赛与有界题上（AMC +1.7、Gaokao +1.2、AIME +0.8），多数基准为最佳或并列最佳。
- **搜索智能体（Table 4）**：6 基准 Avg-6 = 37.80，比 Search-R1（36.00）高 **+1.80**、比次优 StepSearch（36.44）高 **+1.36**，6 个基准领跑 5 个，多跳最重的 2WikiMultiHopQA 上 35.20 vs 27.58（**+7.62**）；唯一未领先的 MuSiQue 由做 step-level reward 的 StepSearch 夺冠。
- **机理证据**：MATH-7.5K 的 7,399 道可解析题按答案形态可分 11 类，其中 5 类有界、合计占 **55.95%**（如 int_small[-10,10] 占 24.41%、盲猜命中率 4.76%；finite_set_listed 的命中率高达 20%）；完全不做推理、恒定输出串 "2" 即可得 **2.69%**，均匀采样 top-10 高频答案串达 **20.6%**（top-100 约 49.3%）；有界题占比随难度单调下降（Level 1 的 69.2% → Level 5 的 45.9%），即早期最容易答对的题正是伪优势最肥的题。Fig. 2/5 显示增益跨数百步持续，非单点 checkpoint 运气。
- **消融（Table 5）**：Avg-8 沿 GRPO 34.24 → 独立归一 34.39 → 纯符号 35.09 → 完整版 36.61 递增；纯符号版在 MATH-500 上回撤 4.80，手写非对称版（+2.5/−1）只有 35.05，说明"数据自适应的力平衡"而非固定偏向才是关键。

## 4. 亮点与贡献（Why it matters）

1. **首次把"猜对的 rollout"系统化为 GRPO 的伪优势**，并给出三个结构上可判定的发生条件——有界答案、开放集里隐藏的有界子集、outcome-only 多轮搜索——把零散现象收进一个统一透镜。
2. **公式级诊断清晰**：借助二值奖励闭式解 Â+ = √(n−/n+)，指出失衡组对"稀有正确"的放大可达约 3.87 倍，且 clip 机制拦不住这一放大。
3. **SIGNBALANCE 工程上极轻**：无参数、不动 surrogate、零额外模型与推理成本，是现有 GRPO 训练管线里"一行替换"级别的修复。
4. **跨任务、跨尺度的实证一致**：0.5B/3B 数学 + 7B 搜索智能体上均有收益且增益跨训练全程稳定，说明这并非小模型的局部现象，也把"GRPO 与任务结构如何互动"摆上台面。

## 5. 局限与可改进点（个人点评）

- **全局尺度 c 是自由超参却几乎未讨论**：它本质上等价于对整体更新幅度的缩放（类似 RLOO 里的 ±1），论文未给出 c 的取值依据或敏感性分析，多少削弱了"无参数"的卖点。
- **开放答案端是"不输"而非"赢"**：Table 2 中 MATH-500 有约 3 个点的回撤，作者归因于伪优势在该域可忽略——但这个 trade-off 对追求全面领先的工程团队仍是需要掂量的点。
- **"更会推理"缺乏直接测量**：作者自认未量化推理置信与不确定度随难度的变化，"消除伪优势 → 更像在推理"主要靠轨迹对比与基准提升间接推断。
- **搜索智能体实验规模偏小**：7B + B=4 下 Avg-6 仅比最强基线高约 1.4~1.8 点，MuSiQue 上还输给做 step-level reward 的 StepSearch——纯换 advantage 的收益上限有待更大规模检验。
- **有界性判定依赖手工答案形态标注**：5/11 类、55.95% 的划分出自语法形状启发式，迁移到答案形态更杂的多模态/GUI 域时，这套诊断如何自动化是未答之问。

## 6. 对 GUI Agent 的可借鉴点（跨域参考专节）

本文是 Agent 方法论论文而非 GUI 落地，但它的机理对 GUI Agent 的 RL 训练几乎构成"精确打击"——GUI 决策天然充满有限候选集：

- **GUI 的每步动作本身就是"多选题"**：agent 每次从有限集合里选元素/动作（点哪个按钮、输什么文本、选哪个菜单项），与 k 选 1 的选择题同构。若 verifier 只看整条任务的最终成败、用 GRPO 训练，乱试凑巧成功的那次点击会被组内计数放大成高梯度——正是伪优势。把 SIGNBALANCE 换进现有管线是最低成本干预。
- **GUI 是比 search agent 更重的"多步结局奖"场景**：一条 GUI 轨迹常有几十次动作而只有一两次真正关键，比 search agent（B≤4）更容易出现"绕远路/碰运气抵达目标与高效路径同分"。可先用 SIGNBALANCE 去掉组内计数放大，再叠加 step-level 或子目标 verifier 做奖励整形——正交于 advantage 设计，正如 StepSearch 相对本文的意义。
- **作者自带背书**：Limitations 主动指出"每一步从有限工具库选工具"与多选同构、经典 GRPO 预期同样受伪优势之害；GUI Agent 正是这类有限动作库场景的典型代表，迁移有论文本身的依据。
- **可借鉴诊断工具**：按表 1 的方式对 GUI 训练集做"有界性盘点"，即可预判是否该换 advantage；配合图 3 式"固定策略得分下限"实验，能量化数据里"不推理也能拿分"的基线有多肥。
- **风险低、可 A/B**：SIGNBALANCE 不改损失结构、不引外部模型，GUI 团队只需替换 advantage 一行即可对照，适合先在现有 GUI Agent RL 管线上快速验证。
