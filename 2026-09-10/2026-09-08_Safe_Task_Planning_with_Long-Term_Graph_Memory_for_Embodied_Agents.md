## 1. 研究背景与要解决的问题

机器人"高层任务规划"要回答的是：给定一句自然语言指令（如"用水壶给植物浇水"），机器人该按什么顺序执行一连串动作。近两年主流做法是把观测和指令丢给 VLM/LLM，靠预训练里学到的常识做零样本规划。问题在于：这些大模型是从互联网文本里学来的，**对物理世界的危险没有概念**——它不知道"插座旁边泼水会触电""炉子上有纸巾会起火"。

已有的安全规划工作（如 IS-Bench 的思维链安全提醒、SaP 的认知提示词、RoboSafe 的知识库检索）基本都假设环境是**全可观测**的：危险物就在当前画面里，只要提示模型"先找风险"就行。但真实机器人只装了一个第一视角相机，处在**部分可观测**环境中。论文开篇给了一个很典型的反例：机器人先前看到过植物旁边有插排，但当它转向植物准备浇水时，插排已经不在画面里，于是即便带着安全提醒的 VLM 也照样把水浇了下去，造成触电隐患。

本文要补的缺口正是：**当危险物已经离开视野、却被历史观测记录过时，如何让智能体仍然记得并规避它。**

## 2. 核心方法 / 思路

论文提出 SafeMem 框架，把问题建模成 POMDP，核心是把"记忆"从模糊的上下文变成结构化的图。整体是一个"感知—记忆—风险评估—规划"的闭环，可分三块：

**（1）长期语义图记忆。** 把环境表示成一张图 G=(V,E)：节点 V 是曾经见过的物体实例（带 ID、包围盒、掩码、类别），边 E 是物体间的语义关系（ON、IN、NEAR、ABOVE、ATTACHED TO 等）。构建时用双通道融合：Gemini 2.5 Flash 负责理解场景、产出候选物体与关系，SAM 2.0 负责精确分割；再用 IoU 把 LMM 的框和 SAM 的掩码对齐、修剪误匹配。因为大模型的空间推理不可靠，作者又用深度图把 ON/IN/NEAR 这类"可计算关系"的三维包围盒算出来做边校正。

**（2）图更新。** 每个时间步生成新图 G_new，与上一时刻的 G_{t-1} 合并：先用掩码 IoU 做二部图匹配，让同一物体跨帧继承持久 ID；新出现物体分配新 ID；**暂时没匹配上的旧节点不删除而是保留**——这是应对遮挡/出视野的关键设计。边方面，新关系覆盖旧关系，涉及不可见物体的旧边保留，而被上一步动作作用过的物体与不可见物体之间的边会被剪掉（因为无法可靠推断），同时按动作语义补新边（比如"把物体放进容器"后补一条 IN 边）。

**（3）安全感知规划。** 一个 LLM 风险预测器读入图记忆（为减轻负担只喂语义节点和关系、不喂框和掩码）和候选动作，判断该动作是否触发危险；若有风险就输出 REPLAN 信号并给出解释，VLM 规划器据此重新生成动作，循环直到无风险。为避免规划器与预测器互相"踢皮球"死锁，引入保守因子 η∈[0,1]：以 η 的概率采纳 REPLAN，η=1 表示完全保守、η=0 表示无视风险。

与已有方法的本质差异：别人靠"提示词让模型自己小心"，本文靠**外部结构化记忆**把已经看过的危险物显式保存下来，使风险推理不再受限于当前视野。

## 3. 关键实验结果

评测在 **IS-Bench**（覆盖触电、火灾、跌落、食物污染四类危险）上进行，作者把原本的全景观测改成**单目第一视角 RGB-D** 以模拟部分可观测，另在 7 自由度 Franka Panda 真机上做了验证。

**部分可观测仿真（表 1，平均 SR/SSR）**：SafeMem 达 **0.79 / 0.59**，而 SaP 为 0.79 / 0.13、CoT 为 0.83 / 0.17、无记忆的 Base 为 0.59 / **0.00**；去掉图记忆的 SafeMem w/o GM 也只有 0.75 / 0.21。也就是说基线任务能做对，但**几乎全部违反安全约束**，SafeMem 把平均安全成功率抬高了约 3~4 倍。分项看，火灾场景 SSR 从 0.00 提到 0.50，食物污染从 0.17 提到 0.50。

**全可观测仿真（表 2）**：SafeMem 平均 0.88 / 0.67，SafeMem w/o GM 0.92 / 0.42，提示词类基线 SSR 仅 0.13~0.21，说明图记忆在全观测下依然有效。

**真机实验（表 3，10 次平均）**：SafeMem 四类任务的 SR 与 SSR **全部为 1.0**；基线 SR 虽高（多为 1.0），但 SSR 普遍掉到 0.0~0.1，凸显 VLM 在真实场景下缺乏物理风险意识。

**消融**：把图记忆换成全历史图像后 SSR 仅 0.13、换成 RAG 文本知识库 0.38、换成纯物体列表 0.17，都远低于图记忆的 0.59——**边（关系）是风险预测的关键**，无效的记忆表示甚至比没有记忆更糟。去掉"不可见物体保留"机制后 SSR 退化到与无记忆相当（0.21）；η=1 比 η=0.8 把安全违规从 6/17 降到 3/17，SSR 从 0.59 升到 0.67。在无危险任务上 SafeMem（0.82）与 Base（0.76）接近，说明风险预测器不会引入多余的无效重规划。

## 4. 亮点与贡献（Why it matters）

- **把"部分可观测"正式引入安全任务规划**：此前工作默认危险物可见，本文明确指出并系统解决了"危险已出视野"这一更贴近真实部署的设定。
- **结构化记忆优于长上下文**：实验直接证明，把全部历史图像塞给模型（SSR 0.13）反而不如显式图记忆（0.59），对"长上下文能否替代记忆"给出了否定答案。
- **记忆设计有细节**：不可见节点保留、动作感知的边更新、深度图校正空间关系，这几处是真正撑起性能的工程要点，而非泛泛的"用个图"。
- **仿真 + 真机双重验证**：真机上 SSR 从 0.0~0.1 直接拉到 1.0，说服力强。
- **保守因子可调**：η 提供了"安全—效率"的显式旋钮，便于按场景风险等级部署。

## 5. 局限与可改进点（个人点评）

- **依赖"危险物曾被观测到"这一前提**：作者自己也承认，SafeMem 无法从物理常识推断从未见过的隐藏危险（如墙体内部的电线），这本质上把安全问题从"推理"降级成了"回忆"。
- **记忆图完全由大模型 + SAM 构建**：物体识别、关系抽取、类别标签任一步出错都会污染整张图，论文没有报告图构建的精度或错误传播分析，鲁棒性存疑。
- **评测规模偏小**：IS-Bench 每类危险的样本数有限（消融里安全违规总数只有 17 次），0.59 与 0.67 这类差异是否稳定缺乏置信区间。
- **η 的概率机制不适用于安全关键场景**：作者也承认，真正高危场景应当用"停机兜底"而非 20% 概率无视风险。
- **未开源**：只给了演示视频页，图记忆与提示词细节虽在附录，但复现仍需自行补齐。

## 6. 对我们的启示 / 可借鉴点

- **"外部显式记忆"是长程 Agent 的通用解法**：SafeMem 证明了让模型自己"记住"不如给一个可读写的结构化存储。做 GUI Agent 时，跨步骤/跨页面的关键状态（如"这个页面之前出现过弹窗""该按钮已置灰"）同样适合用显式记忆而非依赖上下文窗口。
- **记忆要带关系而非只存条目**：消融显示纯物体列表（无边的图）SSR 仅 0.17，而带关系图 0.59。迁移到 GUI，记忆不应只记录"见过哪些元素"，而应记录元素间关系（父子层级、动作前置依赖、控件与页面的归属）。
- **"保留不可见节点"值得借鉴**：GUI 中切换页面后元素消失、返回后又出现，这种"暂时不可见但未消失"的状态与本文场景高度一致，跨帧 ID 继承 + 不删除策略可直接迁移。
- **独立的校验器 + 可重规划回路**：把"生成动作"和"判断动作是否危险"拆成两个模块、并用信号触发重规划，这种"actor + critic + replan"的闭环结构，对 GUI Agent 的误操作防护（如删除、支付、提交等不可逆操作）很有参考价值。

## 7. 延伸阅读

- IS-Bench：VLM 驱动具身智能体交互安全评测基准（本文主要评测平台与 CoT 基线来源）。
- SaP（Safety-As-Policy）：用世界模型虚拟交互学习认知提示词，本文主要对比方法。
- RoboSafe：从预建知识库检索安全逻辑并阻断危险计划。
- SafeVLA / SafeDiffuser：从底层动作层做安全对齐，与本文的高层规划层形成互补。
- HippoRAG：用 PPR 在自动构建的图上做检索增强，与本文的图记忆思路同源。
