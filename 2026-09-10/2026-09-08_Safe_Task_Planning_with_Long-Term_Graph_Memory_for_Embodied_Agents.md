# Safe Task Planning with Long-Term Graph Memory for Embodied Agents

> 一句话 TL;DR：SafeMem 用一张跨帧维护的长期语义图记忆显式保存"看过的危险物"，让具身 agent 在部分可观测下也能规避已出视野的隐患，安全成功率从基线近 0 抬到 0.59。

## 2. 论文要解决的核心问题

- **要解决什么问题**：给定自然语言指令，机器人在**第一视角（egocentric）、部分可观测**的家居环境中生成一系列**安全**的高层动作序列。场景属于通用 Embodied Agent 的任务规划，而非 GUI。

- **为什么重要**：VLM/LLM 规划器从互联网数据预训练而来，**缺乏物理风险意识**——它不知道"插座旁泼水会触电""炉灶上有纸巾会起火"。安全问题不解决，规划再对也会造成设备损坏甚至人身伤害，直接卡住具身智能的落地。

- **现有方法有什么不足**：论文明确批评三类已有安全规划范式——① IS-Bench 的 CoT 安全提醒、② SaP 的认知提示词（world model 学一个"提醒词"）、③ RoboSafe 的预建知识库检索阻断——它们**默认环境全可观测**，即危险物必须在当前画面里才能被提示出来。但真实机器人只有一个第一视角相机，危险物会随视角转动、被遮挡而**离开视野**。论文 Fig.1 给出反例：agent 之前见过植物旁的插排，转身浇水时插排已不在画面，即使带安全提醒的 VLM 也照样把水浇下去，造成触电隐患。

- **Research Gap**：作者的核心 claim 是——**当危险物已被历史观测记录、但当下不可见时，如何让 agent 仍然记得并规避它**。他们把"安全"从"提示模型当心可见风险"升级为"维护跨时间的外部记忆，对不可见风险做推理"。

## 3. 方法核心思想（三层拆解）

### 3.1 一句话概括方法

把环境建模为 POMDP，用一张**跨帧增量更新、保留不可见节点**的语义图作为长期记忆，外加一个**独立的 LLM 风险预测器 + 保守因子调制的重规划回路**，让"生成动作"与"判断动作是否安全"解耦。

### 3.2 方法总览（Pipeline）

- **输入**：egocentric RGB-D 观测 + 自然语言指令 + 预定义低层技能集 Π + 对象标签集 C。
- **输出**：每一步一个可执行的高层动作（如 `PLACE_AWAY(plant, power_strip)`），闭环直到 `DONE()`。
- **模块与连接**：感知—记忆—风险评估—规划四段闭环：
  1. **图构建**：LMM（Gemini 2.5 Flash）提候选物体+关系，SAM 2.0 做精确分割，IoU 对齐修剪误匹配；再用深度图反投影出 3D 包围盒，对 `Rcal`（ON/IN/ABOVE/NEAR/ATTACHED TO）可计算关系做**边校正**。
  2. **图合并（Gt = Merge(Gt−1, at−1, Gnew_t)）**：掩码 IoU 二部图匹配继承持久 ID；新物体赋新 ID；**未匹配旧节点保留不删**（应对遮挡/出视野）；新关系覆盖旧关系，涉及不可见物体的旧边保留，被上一步动作作用物体与不可见物体之间的边剪枝，并按动作语义补新边。
  3. **风险预测**：LLM 读图记忆（只喂语义节点+关系，**省略 bbox/掩码**以减负担）+ 候选动作，输出 REPLAN 信号 + 解释。
  4. **重规划**：VLM 规划器收到 REPLAN 与解释后重新生成动作，循环到无风险；保守因子 η∈[0,1] 控制采纳概率防死锁。

### 3.3 真正的创新点（去伪存真）

- **真·方法创新**：把"长期语义图记忆"正式引入安全任务规划，并给出三处关键机制——**不可见节点保留**、**动作感知的边剪枝/补边**、**深度图驱动的空间关系校正**。这三者是 ablation 中真正撑起性能的点，而非泛泛"用个图"。
- **工程组合**：POMDP 建模、LLM 风险预测、actor-critic 式重规划回路、SAM 分割、深度反投影，都是已有组件；本文的创新在于把它们按"记忆—校验—重规划"组合成闭环。
- **对性能提升最关键的设计**：**边（关系）的存在**是首要因素——object-list（无边图）SSR 仅 0.17，graph 0.59；其次是**不可见节点保留**（去掉后 SSR 从 0.59 跌到 0.21）与**动作感知边更新**（去掉后 0.38）。
- **证据不足 / 仅声称有效**：图构建的精度与错误传播（物体误识别/关系误抽取如何污染下游）**没有定量报告**；η 的概率机制作者自己承认不适用于安全关键场景，需换成停机兜底。

## 4. 具体技术细节

### 4.1 模型结构

- **base model**：VLM 规划器与 LLM 风险预测器**均为 GPT-4o**（未微调，纯提示推理）。图构建用 **Gemini 2.5 Flash（LMM）** + **SAM 2.0（分割）**。三者全部冻结，无训练。
- **关系闭集** R 共 7 种：ON、IN、ABOVE、NEAR、ATTACHED TO、PART OF、HOLDING；其中前 5 种属可计算子集 `Rcal`（附录给出明确几何规则，如 `IN(i,j)=I(Bi⊆Bj)`、`NEAR` 用物体 3D 对角线长度做自适应阈值），冲突优先级 IN > ON > ATTACHED TO > ABOVE > NEAR。

### 4.2 训练流程

无训练阶段。本方法属推理时增强（inference-time），不涉及 SFT/RL 等任何参数更新。

### 4.3 推理流程

- **多步闭环**（规划-执行，非 ReAct 单步反思）：每步 VLM 生成一个候选动作 → 风险预测器按图记忆判 SAFE/UNSAFE → 若 UNSAFE 且随机数 < η 则带解释重规划，循环直到 SAFE → 执行动作 → 新观测 → 更新图 → 下一步。终止条件：任务目标达成或规划器输出 `DONE()`。
- **保守因子** η=0.8（默认）：以 0.8 概率采纳 REPLAN。η=1 完全保守、η=0 无视风险。
- **成本代价**（Table 11）：SafeMem 平均每步 9425.40 tokens / 17.62s，较 Base VLM Planner（3979.77 / 10.33s）和 w/o GM（6101.48 / 12.43s）明显更重——这是引入图记忆+独立预测器+重规划回路的直接开销。

## 5. Benchmark 与实验设置

### 5.1 Benchmark 一览表

| Benchmark | 场景 | 任务类型 | 数据规模 | 输入格式 | 输出格式 | 评测指标 |
|---|---|---|---|---|---|---|
| IS-Bench（改造版，OmniGibson 仿真） | General（家居） | 高层安全任务规划 | 17 个任务：触电 3、火灾 2、跌落 6、食物污染 6 | 单目 egocentric RGB-D（1280×720）+ 指令 + BDDL 目标 | 预定义技能集的高层动作 | SR（任务成功率）、SSR（安全成功率） |
| 自建真机平台 | General（家居桌面） | 高层安全任务规划 | 4 类危险各 1 任务，各跑 10 次 | RGB-D（RealSense D405，848×480）+ 指令 | 高层动作 | SR、SSR |

> 关键改造：原 IS-Bench 是**全景多相机全可观测**，作者改为**单目第一视角 RGB-D** 以模拟部分可观测；全可观测设置保留原配置、仅加深度图做图构建。

### 5.2 实验结果分析

**主结果（部分可观测，Table 1，平均 SR/SSR）**：SafeMem **0.79 / 0.59**；SaP 0.79/0.13、CoT 0.83/0.17、Base 0.59/**0.00**、SafeMem w/o GM 0.75/0.21。即基线**任务能做对但几乎全违反安全约束**，SafeMem 把 SSR 抬高约 3~4 倍。分项亮点：火灾 SSR 从 0.00→0.50，食物污染 0.17→0.50，跌落 0.17→0.67，触电 0.33→0.67。

**全可观测（Table 2，平均）**：SafeMem **0.88 / 0.67**，w/o GM 0.92/0.42，提示词类基线 SSR 仅 0.13~0.21——图记忆在全观测下依然有效。

**真机（Table 3，10 次平均）**：SafeMem 四类 SR 与 SSR **全部 1.0**；SaP/CoT 的 SSR 全部 0.0，Base 至多 0.1，凸显 VLM 在真实场景缺乏物理风险意识。

**Ablation 说明**：
- 记忆形式（Table 4）：graph 0.59 > RAG 文本知识库 0.38 > object-list（无边）0.17 > full 全历史图像 0.13。**"全历史上下文"最差**，否定了"长上下文能替代记忆"；**边是关键**。
- 组件（Table 5）：去掉不可见保留 → SSR 0.21（≈无记忆）；去掉动作感知边更新 → 0.38。二者都不可少。
- η（Table 6）：η=0.8 时安全违规 6/17、SSR 0.59；η=1 时违规降到 3/17、SSR 0.67，但延迟更高。
- 无危险任务（Table 7）：SafeMem 0.82 vs Base 0.76，说明风险预测器不引入多余重规划。

## 6. 亮点与贡献（Why it matters）

1. **首次把"部分可观测"正式引入安全任务规划**：从"危险物可见"推进到"危险物已出视野"，更贴近真实单目部署，并系统解决了记忆-推理问题。
2. **用实验证伪"长上下文即记忆"**：全历史图像 SSR 仅 0.13，结构化图 0.59，对当前"塞更多历史进上下文"的流行做法给出明确否定答案。
3. **记忆设计有硬细节**：不可见节点保留、动作感知边更新、深度图校正空间关系，三处机制均有 ablation 支撑，可复现性强。
4. **仿真 + 真机双重验证**：真机 SSR 从 0.0~0.1 拉到 1.0，说服力强；且统一低层技能集，隔离了高层规划效果。
5. **保守因子 η 提供显式安全-效率旋钮**：可按场景风险等级调节重规划激进程度。

## 7. 局限与可改进点（个人点评）

- **本质是"回忆"而非"推理"**：作者自认 SafeMem 无法从物理常识推断**从未被观测过**的隐患（墙内电线、隐藏物体、隐性环境动力学）。这把安全从"推理"降级成"记忆匹配"，覆盖面受限于曾经看到过。
- **图构建无误差分析**：物体识别、关系抽取、类别标签任一环出错都会污染整张图并向下游传播，论文未报告图构建精度，鲁棒性存疑。
- **评测规模偏小**：每类危险仅 2~6 个任务、真机每类仅 10 次，且消融里安全违规总数只有 17 次（6/17 vs 3/17），0.59 与 0.67 这类差异**缺乏置信区间**，稳定性存疑。
- **概率式重规划不适用于高危场景**：20% 概率无视风险在安全关键场景不可接受，作者也承认应改为停机兜底。
- **未开源**：仅项目主页 + 附录提示词，图记忆实现细节需自行补齐，复现门槛高。
- **cost 偏高**：每步 17.62s / 9425 tokens，比裸规划器慢约 70%，对实时闭环控制是现实约束。

## 8. 对我们的启示 / 可借鉴点

> 本篇属【Agent 方法论域】（具身智能，非 GUI 落地），故单列对 GUI Agent 的可借鉴点。

- **"外部显式记忆"是长程 Agent 的通用解法**：SafeMem 证明让模型自己"记住"不如给一个可读写的结构化存储。GUI Agent 跨步骤/跨页面的关键状态（"该页之前弹过窗""按钮已置灰""表单已提交"）同样适合显式记忆，而非无限扩张上下文窗口。
- **记忆要带关系，而非只存条目**：消融显示纯对象列表 SSR 仅 0.17、带关系图 0.59。迁移到 GUI，记忆应记录元素间关系（父子层级、动作前置依赖、控件与页面归属），而非孤立元素。
- **"保留不可见节点 + 跨帧 ID 继承"可直接迁移**：GUI 切换页面后元素消失、返回后又出现，与本文"暂时不可见但未消失"高度一致，跨帧 ID 继承 + 不删除策略可移植到页面/控件状态追踪。
- **actor + critic + replan 的闭环防护**：把"生成动作"与"判断动作是否安全"拆成两个模块并用信号触发重规划，对 GUI 的不可逆操作（删除、支付、提交）误操作防护极具参考价值。
- **成本账要提前算清**：SafeMem 每步延迟 +70%，提醒我们在 GUI Agent 里引入独立校验器时同样要权衡 token/延迟开销。

## 9. 延伸阅读

- IS-Bench（Lu et al., AAAI 2026）：VLM 驱动具身 agent 交互安全评测基准，本文主要评测平台与 CoT/Base 基线来源。
- SaP（Ni et al., RA-L 2025）：Safety-As-Policy，用 world model 虚拟交互学习认知提示词，本文主要对比方法。
- RoboSafe（Wang et al., 2025）：从预建知识库检索可执行安全逻辑并阻断危险计划。
- SafeVLA / SafeDiffuser / SafeBimanual：从底层动作层做安全对齐，与本文高层规划层互补。
- HippoRAG：用 PPR 在自动构建的图上做检索增强，与本文图记忆思路同源。
