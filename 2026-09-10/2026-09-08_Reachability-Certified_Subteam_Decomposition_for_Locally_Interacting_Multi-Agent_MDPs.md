# Reachability-Certified Subteam Decomposition for Locally Interacting Multi-Agent MDPs

> 一句话 TL;DR：用"速度界+奖励包络"构造策略无关的可达性证书，在规划前把多智能体按容量拆成固定子队，并给删除跨队奖励后的价值损失上界。

## 2. 论文要解决的核心问题

- **要解决什么问题**：多智能体系统在"持久通信规模有硬上限"（同一时刻最多 L 个智能体维持共享状态信道）时，**规划之前**就决定哪些智能体应该组成固定协作子队，而不求解任务本身。
- **为什么重要**：这是部署层面的资源决策——"每个规划器最多看到 L 个智能体"这句资源承诺，只有在分组持久固定时才精确成立。若分组随可见性动态漂移，局部接触的连通分量会像滚雪球一样合并，容量约束便失去意义。
- **现有方法有什么不足**：论文明确反驳了两个直觉基线。①"按当前邻近度分组"——此刻分离的智能体可能几步后进入交互范围，且移动链条会让连通分量膨胀；②"按静态奖励图分组"——一个很大的配对奖励若很多步内无法触达，其对当前价值的贡献会被折扣衰减到几乎为零，此时判为"强依赖"是错的。已有工作 LIMDP 刻画了动态空间依赖与状态相关通信分组，但其执行分组随可见性变化，不提供固定分组的价值风险上界。
- **Research Gap**：能否**仅凭当前状态、不求解任务**，为"容量受限的固定分组"给出可计算、与策略无关的价值风险上界，并据此选子队？这就是 RCSD（Reachability-Certified Subteam Decomposition）声称补上的缺口。

## 3. 方法核心思想（三层拆解）

### 3.1 一句话概括方法

把"几何可达时间下界"与"奖励包络"相乘并折扣，得到每条配对边的亲和度，删掉跨队亲和度之和最小（即保留队内亲和度最大）的分组即为子队，该亲和度和就是价值损失上界。

### 3.2 方法总览（Pipeline）

- **输入**：初始状态 x、容量 L、折扣 γ、合法参数上界（速度 v_i、交互范围 R_ij、奖励包络 b_ij）、一个划分求解器、一个队内规划器。
- **输出**：固定划分 P、证书 B_P(x)、乘积队内策略 π̂_P，并在原始 MDP 中执行。
- **四大模块（数据流）**：①**交互几何**：由当前距离与速度上界算最早接触时刻下界 τ_ij(x)；②**可达性评分**：把两方向包络相加 λ_ij=b_ij+b_ji，折扣后得亲和度 q_ij(x)=λ_ij·γ^{τ_ij}/(1−γ)；③**容量划分**：在 |C|≤L 约束下最大化队内亲和度之和（等价最小化跨队证书 B_P）；④**认证执行**：只在"规划替身"的 cut MDP 里删掉跨队奖励，各队独立规划，得到的队策略放回原始 MDP 执行。

### 3.3 真正的创新点（去伪存真）

- **真·方法创新**：初始状态下的**异构逐边证书**（每条边由距离、速度、范围、双向包络综合出各自的 τ_ij 和 q_ij），以及"**对任意容量合法划分都成立**"的策略级删除界（定理 2）。这与 LIMDP 的可见性分组形成本质区别。
- **工程组合**：容量约束的联盟形成目标（式 9）本身是已知优化问题 [19]；RCSD 只是把异构亲和度作为边代价代入。子集 DP（Exact）、贪心合并（Greedy）、匹配+收缩（MnM-sum）都是既有求解器，**不保证近似比**。
- **对性能提升最关键的设计**：q_ij 把"奖励包络 λ_ij"与"接触延迟 τ_ij"**分开处理**——对照实验显示，只保留距离（Distance）或只保留包络（Envelope）都不如两者结合（ARR 分别 28.80%、25.31% vs 完整 56.04%）。
- **证据不足 / 仅声称有效**：8–20 智能体层级结论**混合甚至不利**（Envelope-only 与 Value-MIP 反而优于 RCSD）；缺失特征对照族同时改了多个生成参数，作者自己声明"不是单变量因果消融"。

## 4. 具体技术细节

### 4.1 模型结构（base model）

**非神经网络、无视觉编码器、无训练**。base model 是有限折扣 MDP M=(X,A,K,r,γ)，0<γ<1，其中状态/动作按智能体因子化 X=∏_i X_i、A=∏_i A_i。两个关键结构假设：

1. **转移因子化**：K(x'|x,a)=∏_{i=1}^n K_i(x'_i|x_i,a_i)；每个局部状态有位置 p_i(x_i) 在同一度量空间，每步位移几乎必然 ≤ v_i。
2. **奖励分解**：r(x,a)=Σ_i r_i(x_i,a_i)+Σ_{i≠j} r_{ij}(x_i,x_j,a_i,a_j)；对称范围 R_ij 内 |r_ij|≤b_ij，超出则 r_ij=0。

### 4.2 训练流程

**不训练**。所有值函数由线性求解与收敛动态规划精确算出，策略为精确平稳 Markov 策略，回避训练方差。

### 4.3 推理 / 规划流程

**单次规划前计算，非多步循环**。核心三步递推：τ_ij(x)=⌈[D_ij(x)−R_ij]⁺/(v_i+v_j)⌉（速度-限制接触下界）；q_ij(x)=λ_ij·γ^{τ_ij}/(1−γ)；B_P(x)=Σ_{i<j:cut} q_ij(x)。三条理论界构成保证层次：

- **引理 1（速度限制接触）**：任意可行轨迹上，t<τ_ij 时刻该配对的顺序奖励全为零。
- **定理 2（策略级删除证书）**：对任意在两模型间保持不变的平稳 Markov 策略 π，|V_M^π(x)−V_{M_P}^π(x)|≤B_P(x)。
- **推论 4（执行后悔）**：执行 cut 最优乘积策略，V_M^*(x)−V_M^{π̂_P}(x)≤2B_P(x)；带符号奖励下两个常数（B 与 2B）最坏紧。推论 5 放宽到近似规划器，界为 2B_P+ε̄_P。

复杂度：配对待 O(n²)；精确子集 DP 时间 O(nL·L²+2^n·n^{L-1})、空间 O(2^n+nL+n²)；Greedy 上界 O(n³L²)。持久链路数 Σ_C|C|(|C|−1)≤n(L−1)，把队内规划维度从 n 降到 L，但**仍保留对 L 的指数依赖**。

## 5. Benchmark 与实验设置

### 5.1 Benchmark 一览表

| Benchmark | GUI 场景 | 任务类型 | 数据规模 | 输入格式 | 输出格式 | 评测指标 |
|---|---|---|---|---|---|---|
| Meeting-Port Corridor | General（非 GUI，5 智能体走廊） | 子队划分 + 精确规划 | 4,500 实例/族 × L∈{2,3}；7⁵=16,807 状态、3⁵=243 动作 | 位置/速度/包络/范围参数 | 固定划分 + 队策略 | 归一化执行后悔、ARR |
| 随机二维障碍网格 | General（非 GUI，含障碍/随机滑移） | 划分 + 精确/控制器库规划 | 128 四智能体 + 120 地图（n∈{8,12,16,20}） | 随机 2-D 位置/速度/范围 | 划分 + 策略 | 无界/库内后悔、界违例数 |
| 有限 MDP 验证 | General（定理审计） | 定理反例验证 | 648 设置、124,380 转移等 | 参数化 MDP 族 | — | 违例计数、数值残差 |

### 5.2 实验结果分析

- **主结果**：Meeting-Port Corridor（γ=0.85，交互范围 0）上 RCSD-Exact 归一化执行后悔 **0.03910**，对比 Uniform 0.08895、Distance-only 0.05492、Envelope-only 0.05235。聚合后悔降幅（ARR）**56.04%（对 Uniform）、28.80%（对 Distance）、25.31%（对 Envelope）**，配对 95% 自助区间均不含 0（Holm p=0.000030）。证书 B_P 与实际后悔的组内 Spearman 中位数 **0.7143**（seed 聚类 95% CI [0.7091, 0.7212]）。随机二维 exact 层级：RCSD 无界后悔比 Uniform/Distance/Current 低 **21.6%/24.1%/14.8%**；Envelope 仅 2.6% 差距、不确定。有限 MDP 验证零违例，最大数值残差 **1.42×10⁻¹⁴**，one-state fixture 精确达到 B 与 2B 两个常数。
- **Ablation 说明了什么**：①**距离 vs 包络的分离**：Distance-only（去掉奖励幅度）与 Envelope-only（去掉接触延迟）共享同一划分支撑与链路预算，故与 RCSD 的差异只能归因于 q_ij 中的单一因子——两者都不如完整 q_ij，证明"几何邻近、奖励大小、可达时间"三者缺一不可。②**缺失特征对照族**（非严格单变量消融）：证书输入不含决定协作的特征时 ARR 骤降到 **0.03096**，效应量 d_z=0.1000、胜率 0.5164（接近抛硬币），signed ρ=0.1643，说明 RCSD 的优势强烈依赖"证书输入编码了协作相关信息"。③**求解器对比**：RCSD-Greedy 归一化证书 gap 中位 0.01110（p90 0.05287、max 0.13845），是经验近似而非近似定理；100 智能体 L=4 时中位构造耗时 Greedy 0.0545s、MnM-sum 0.2333s（**不含亲和度构造与队 MDP 规划**）。

## 6. 亮点与贡献（Why it matters）

1. **把通信分组变成"可认证的资源决策"**：分组在规划前一次固定，使"每规划器最多看 L 个智能体"成为精确可验证的资源承诺，而非执行中漂移的可视化。
2. **证书先于规划可得**：B_P(x) 不依赖计划价值或事后后悔，可在求解任务前给出最坏风险，天然适合安全关键部署的准入检查。
3. **对任意可行划分成立**：定理 2 不限于最优划分，求解器可替换、可提前停止且仍持有有效证书。
4. **方法论诚实**：主动报告混合/不利结果（大层级 Value-MIP 与 Envelope-only 反超 RCSD），并把"构造快"与"端到端规划质量"分开报告，避免把可扩展构造误当可扩展规划。

## 7. 局限与可改进点（个人点评）

- **证书天然保守**：q_ij 从接触下界起就按完整包络满额收费，牺牲紧度换策略无关性与规划前可算性；作者也承认最小化 B_P ≠ 最小化真实后悔（regret-to-certificate 比率仅 .076/.206）。
- **假设偏强**：状态/动作有限、转移与动作乘积因子化、奖励为前转移有限范围有序配对、范围对称、策略须在两模型间原样不变。耦合动力学、共享动作约束、高阶奖励、动态重划分、一般 Dec-POMDP 观测结构均不在覆盖内。
- **规模证据不对称**：真正端到端精确评估只到 5 智能体；8–20 智能体仅在固定四控制器库内评估；100 智能体只测划分构造。所谓"可扩展"目前只是构造层面的结论。
- **无学习型/真实系统对比**：全为精确规划与合成网格，未与学习型动态分组方法在同一信息结构下直接比较，Value-MIP 反超更提示"最紧证书"未必等于"最好选择"。

## 8. 对我们的启示 / 可借鉴点

- **把"信息可见范围"当一等资源设计**：多工具 Agent 常默认所有子 Agent 可见全部上下文。可借鉴 RCSD 显式设定"每规划器可见实体上限"，用可达性/重要性打分决定谁与谁共享状态，同时控制 token 成本与协调错误。
- **"现在近"≠"将来相关"**：跨工具、跨页面依赖常若干步后才显现。可用 τ 的"最早可能交互步数"对依赖做折扣，避免把远期、难触达的依赖误当强耦合而过早绑死。
- **先给风险上界、再决定分组**：这类"规划前证书"适合做 Agent 编排的准入检查——若某方案最坏损失上界已超容忍度，就应增大分组容量或换方案（对应容量规则 2B*_L+ε̄_L≤δ）。

**对 GUI Agent 的可借鉴点**：核心是把"可达性认证的子队分解"映射到 GUI 多 Agent 的分工安全。(1) 长流程 GUI 任务中，页面导航、表单填写、弹窗处理等子 Agent 不应无差别共享全部屏幕状态，而可按"未来多快会互相影响"划分固定协作组，用受限信道降低上下文膨胀与冲突；(2) 把"跨队奖励删除"类比为"忽略跨模块依赖后的规划"，用一个保守上界（如某依赖最坏造成多少步返工）认证该忽略是否安全，在提交高风险操作前判断分组是否可靠；(3) 证书对任意合法划分成立，故 GUI 编排可在通信预算下先拿"风险凭证"再执行动作，天然契合"先评估、后点击"的安全范式。

## 9. 延伸阅读

- **LIMDP**（Deweese & Qu, ICML 2024）：动态空间依赖与状态相关通信分组，本文最直接的前置工作。
- **Transition-independent / factored MDP**（Becker et al. 2004；Guestrin et al. 2001）与 payoff propagation（Kok & Vlassis 2006）中的稀疏协调图。
- **Fiscko et al.**（CDC 2023 / IEEE TCNS 2025）：簇预算下优化可达状态空间规模的 transition-independent MDP 聚类。
- **Correlated Policy Optimization**（Chen et al., ICLR 2026）：用依赖分数动态分配 DAG 边预算，可对照其学习型分组路线。
- **容量受限联盟形成**（Levinger et al., AAMAS 2024）：RCSD-Exact 子集 DP 的优化背景与近似结果。
